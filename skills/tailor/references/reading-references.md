# Reading references — take the DNA, not the surface

A reference image is evidence of taste. The job is to find *why* the person likes it and carry that
into a website, not to reproduce the image. Copying a poster's layout gives a site that reads badly
on a phone and may infringe someone's work; carrying its colour logic and attitude gives a site that
feels related and is still original. (Real-world example: a YouTube channel style that began as one
infographic poster kept only its red/black/white palette and the way colour was used; texture,
type and components were added later, and the result no longer resembles the poster at all.)

## What to extract from each image

Write these down per image before deciding anything.

1. **Colour roles and proportions** — not just a list of hex values. Which colour is the ground, which
   carries text, which is the accent, roughly what share each takes (e.g. 70 / 25 / 5). Sample real
   values; name them in plain words too ("oxblood", "newsprint"). Note whether colours are flat,
   printed (slightly off, overprinted), photographic or glowing.
2. **Type character** — serif / sans / slab / mono / display / hand; weight contrast; width
   (condensed, wide); case (caps, mixed); tracking; whether type is used as image (huge, cropped,
   rotated) or as quiet text. Name candidate free web fonts with the same character, not the same
   name.
3. **Composition** — symmetric or not, centred or edge-anchored, dense or airy, grid visible or
   hidden, one focal point or many, where the eye lands first.
4. **Texture and surface** — flat, grain, halftone, paper, photo, noise, scan lines, print
   misregistration. Texture is powerful and easy to overdo; note how *much* of it there is.
5. **Shape language** — sharp corners or round, lines vs blocks, organic vs geometric, borders or none.
6. **Era and mood** — decade, place, three mood words.
7. **The hook** — the one thing that makes this image memorable. Usually this is what the person
   actually fell for. Ask yourself what they would miss if it were gone.

## Several references

Lay the notes side by side. What repeats is the taste (e.g. all three use one loud colour on a dark
ground); what differs is noise (one is a photo, one is illustrated). If two references clearly
contradict, ask the person which one is closer — that answer is very informative.

## Translating a poster to a website

| On the poster | On the website |
|---|---|
| One giant headline | The first screen's headline; keep the scale contrast, let it wrap well on phones |
| A grid or column structure | The section grid; on phones collapse to one column but keep the alignment logic |
| Dense, layered collage | One or two sections that are allowed to be dense; give reading sections calm space |
| Texture over everything | A light texture on grounds/large areas only; never under body text where it hurts reading |
| Tiny decorative text | Real, readable small text (≥ 14 px) — or drop it |
| Fixed single frame | A sequence: decide what the visitor sees first, second, third while scrolling |
| Colour used at full strength everywhere | Same palette, but body text needs contrast, so assign roles |

Readability, speed and phone use win any conflict with the reference. Say so in the DNA when you
had to soften something, so the person knows it was a choice.

## When there are no images: words as references

Cultural comparisons translate into concrete choices. Reason it out explicitly:

- "An old pharmacy" → enamel-white and bottle-green, apothecary label frames, condensed caps in
  small sizes, centred symmetric labels, serif with old-style figures for prices.
- "A Wes Anderson film" → symmetric centred compositions, a narrow pastel palette with one saturated
  colour, Futura-like geometric caps (choose a free alternative), framed sections like title cards.
- "1980s city-pop album cover" → sunset gradients *only because the reference demands it*, chrome
  or italic display type, airbrushed shapes, wide-tracked caps, a single horizon line motif.

Always name the reasoning, so the DNA shows where each choice came from.

## Honesty rules

- Don't reproduce a reference's artwork, photos, logo, mascot or copy.
- Don't build a look-alike of a real brand's site; if someone asks for "exactly like X.com", take
  the qualities they admire and make it theirs.
- If you can't actually see an image (no vision tool / broken file), say so instead of guessing.
